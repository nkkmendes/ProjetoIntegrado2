Design System do Fluxa

Norma visual da aplicação. Toda tela nova ou alterada usa apenas os tokens e componentes desta página. O que não está aqui não existe na interface.

Como usar no Django

Carregue as fontes e os dois arquivos CSS, nesta ordem, no <head> do template base. Nenhuma tela carrega outro CSS.

{% load static %}
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Open+Sans:wght@400;600&family=Roboto+Mono:wght@400;600&display=swap" rel="stylesheet">
<link rel="stylesheet" href="{% static 'css/fluxa-design-tokens.css' %}">
<link rel="stylesheet" href="{% static 'css/fluxa-components.css' %}">

Com o servidor rodando, esta página fica em http://127.0.0.1:8000/static/design-system/index.html.

Regras

  1. Só tokens semânticos. Telas e componentes usam --fluxa-color-action-primary, nunca --fluxa-color-blue-700 nem um hexadecimal.
  2. Nada fora da lista. São 13 cores, 5 tamanhos de fonte, 2 pesos, 3 raios e 6 espaçamentos. Precisa de outro valor? Ele é proposto no arquivo de tokens, nunca criado na tela.
  3. Sem CSS por tela. Sem <style>, sem style="", sem arquivo CSS específico de uma página.
  4. Três botões, três feedbacks. Botão é primário, secundário ou terciário. Feedback é sucesso, aviso ou erro.
  5. Acessível por padrão. Todo campo tem <label>; foco sempre visível; estado nunca comunicado só por cor.

Cores

A paleta tem 13 cores: 3 azuis, 4 neutros e 3 pares de feedback. As 3 cores marcadas como “tema escuro” só existem para o modo escuro.

Formulário

Campos ficam em um .fluxa-form-grid (--2, --3 ou --4 colunas; __full ocupa a linha). Cada campo é um .fluxa-field: rótulo, controle, ajuda e erro, nesta ordem.

Lançar notas
Formato AAAA.S

A nota deve estar entre 0 e 10.

{# templates/components/field.html  —  {% include "components/field.html" with field=form.g1 %} #}
<div class="fluxa-field">
  <label class="fluxa-field__label" for="{{ field.id_for_label }}">{{ field.label }}</label>
  {{ field }}
  {% if field.help_text %}<span class="fluxa-field__hint">{{ field.help_text }}</span>{% endif %}
  {% for erro in field.errors %}<p class="fluxa-field__error">{{ erro }}</p>{% endfor %}
</div>

# forms.py — a classe vai no widget, nunca no template
widgets = {

Estado de um item (linha de tabela, card). Formato pílula, borda 1px na cor do texto, texto 12px semibold.

AppShell

Estrutura de toda tela autenticada: barra lateral (marca, navegação, usuário) e conteúdo. Abaixo de 1024px a barra vai para o topo. O item da página atual recebe aria-current="page".

FilterPanel

Filtros de uma listagem. Envia por GET, para o filtro ficar na URL. “Limpar” é terciário; “Filtrar” é primário.

<form class="fluxa-filter-panel" role="search" method="get" action="{% url 'filtrar_disciplinas' %}">
  <div class="fluxa-field">
    <label class="fluxa-field__label" for="busca">Buscar disciplina</label>
    <input class="fluxa-input" id="busca" name="q" type="search" value="{{ request.GET.q }}">
  </div>
  <div class="fluxa-page-actions">
    <a class="fluxa-button fluxa-button--tertiary" href="{% url 'fluxograma' %}">Limpar</a>
    <button class="fluxa-button fluxa-button--primary" type="submit">Filtrar</button>
  </div>
</form>

Dialog

Janela modal com <dialog> nativo. Uso obrigatório para confirmar ações que apagam ou sobrescrevem dados. Título em forma de pergunta; o botão de confirmação (primário) repete o verbo; “Cancelar” é secundário.

<button class="fluxa-button fluxa-button--secondary" type="button" data-open-dialog="confirmar-exclusao">Excluir</button>

<dialog class="fluxa-dialog" id="confirmar-exclusao" aria-labelledby="confirmar-exclusao-titulo">
  <form method="post" action="…">{% csrf_token %}
    <div class="fluxa-dialog__header"><h2 class="fluxa-dialog__title" id="confirmar-exclusao-titulo">Excluir “Plano 2027”?</h2></div>
    <div class="fluxa-dialog__body"><p>Esta ação não pode ser desfeita.</p></div>
    <div class="fluxa-dialog__footer">
      <button class="fluxa-button fluxa-button--secondary" type="submit" formmethod="dialog">Cancelar</button>
      <button class="fluxa-button fluxa-button--primary" type="submit">Excluir</button>
    </div>
  </form>
</dialog>
