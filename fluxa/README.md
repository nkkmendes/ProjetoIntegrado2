# Fluxa - Django

Estrutura inicial do Django para o projeto de matrícula.

Para rodar, abra o terminal dentro da pasta `fluxa`:

```bash
python -m pip install -r requirements.txt
python manage.py check
python manage.py migrate
python manage.py runserver
```

Depois abra: http://127.0.0.1:8000/

Nesta atividade foi criada apenas a base do Django e uma página simples para testar.
As telas de Planejamento e Simulação de Matrícula ainda não foram integradas.
